# metrics-aggregator-core

Real-time rolling window metrics collector and time-series histogram compressor.

[![CI](https://github.com/placeholder/metrics-aggregator-core/actions/workflows/ci.yml/badge.svg)](#)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Overview
A lightweight, high-reliability Python utility package developed for cloud-native microservices and pipeline health processing.

## Quickstart
```bash
pip install -r requirements.txt
python metrics_aggregator_core/core.py
```

## Running Tests
```bash
python -m unittest discover tests
```
